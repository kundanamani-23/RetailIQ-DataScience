## Abstract

RetailIQ is a full-cycle e-commerce analytics project that focuses on understanding customer behavior and sales performance using retail transaction data. The main aim of the project is to convert raw e-commerce data into useful information that can help in understanding how customers purchase products and how the business is performing. The dataset is analyzed to identify important patterns related to sales, customers, products, and revenue.

The project includes different stages such as data cleaning, preprocessing, exploratory data analysis, and visualization. The data is studied to find the products that perform well, customer purchasing patterns, sales trends, and other factors that affect overall business performance. Different charts and statistical analysis techniques are used to make these patterns easier to understand and compare.

An interactive dashboard is also developed to present the important findings in a simple and user-friendly manner. The dashboard allows users to view sales trends, customer segments, product performance, revenue-related information, and other key metrics. Overall, RetailIQ demonstrates how data analytics can be used in the e-commerce sector to understand customers, monitor sales performance, identify useful business patterns, and support better data-driven decision-making.

## Project Objective

The main objectives of RetailIQ are:

- To analyze e-commerce customer purchasing behavior.
- To identify important sales trends and patterns.
- To analyze product performance and revenue.
- To segment customers based on their purchasing behavior.
- To perform data cleaning and exploratory data analysis.
- To develop an interactive dashboard for visualizing important insights.
- To support better business decisions using data-driven insights.

## Dataset

The project uses an e-commerce retail transaction dataset containing information related to customer purchases, products, quantities, prices, and transaction details.

The dataset will be cleaned and preprocessed before performing exploratory data analysis and developing the analytical model.

## Setup and Execution
### 1. Clone the Repository

```bash
git clone https://github.com/kundanamani-23/KLH-CSE-2026-27-2420030558-RetailIQ.git

cd KLH-CSE-2026-27-2420030558-RetailIQ
```

### 2. Install Required Libraries

```text
pip install pandas numpy matplotlib seaborn scikit-learn streamlit jupyter
```

### 3. Add the Dataset

Place the required e-commerce dataset inside the project directory.

```text
KLH-CSE-2026-27-2420030558-RetailIQ/
│
├── data/
│   └── retail_data.csv
│
├── notebooks/
├── src/
├── dashboard/
├── README.md
└── requirements.txt
```
### 4. Run the Analysis

Open Jupyter Notebook:

```bash
jupyter notebook
```

### 5. Run the Dashboard

The interactive dashboard will be developed using Streamlit.

```bash
streamlit run dashboard/app.py
```
